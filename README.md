# ФинБалансика

Мобильное приложение для учёта доходов, расходов и финансовых целей.

## Возможности
- Баланс, доходы/расходы
- Операции с категориями
- Аналитика (неделя / месяц / год) + диаграммы
- Финансовые цели с прогрессом
- Тёмная тема и режим приватности
- Данные только на устройстве (localStorage)
- PWA + Android APK через Capacitor

## Веб / PWA
Откройте `www/index.html` или `index.html`.

## APK
Автосборка GitHub Actions (debug APK).

После успешного run:
1. Actions → Build Android APK → Artifacts → `finbalansika-apk`
2. Или Releases

Репозиторий: https://github.com/abrorismurzaev2-cpu/finbalansika
