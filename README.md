# ФинБалансика

Мобильное приложение для учёта доходов, расходов и финансовых целей.

## Возможности
- Баланс, доходы/расходы за месяц
- Операции с категориями
- Аналитика (неделя / месяц / год)
- Финансовые цели
- Тёмная тема и режим приватности
- Данные только на устройстве (localStorage)

## Веб
Откройте `index.html` или GitHub Pages.

## APK
Сборка через GitHub Actions → Releases → `finbalansika-release.apk`
